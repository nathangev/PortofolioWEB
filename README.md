## Tech Stack

- **Backend:** Laravel (PHP)
- **Frontend:** Blade, JavaScript
- **Build tool:** Vite
- **Styling:** Tailwind CSS
- **Database:** SQLite (dev)

## Getting Started

```bash
# Install PHP dependencies
composer install

# Install JS dependencies
npm install

# Set up environment
cp .env.example .env
php artisan key:generate

# Run database migrations
php artisan migrate

# Start dev servers
npm run dev
php artisan serve
```

## Project Structure

```
app/            → Application logic (controllers, models)
resources/      → Blade views, JS, CSS, 3D assets
routes/         → Web routes
database/       → Migrations, seeders
config/         → Portfolio & app configuration
```
